# VIVI 🚫 Deprecated

> **Status: Deprecated**  
> This project is no longer actively maintained. The repository is kept public for portfolio and historical reference.

**VIVI** was a Telegram-native trading agent built on **Base** (2024–2025).

It allowed users to trade tokens directly inside Telegram group chats, used by **100+ communities** and generating **600+ ETH** in organic trading volume.

## Key Features

- Trade any token on Base directly from Telegram
- Wallet creation and management inside the bot
- Send / tip / transfer tokens using Telegram usernames
- Multi-send and batch transactions
- Referral and points system
- Used across 100+ Telegram communities
